갤럭시로 러닝 코치 연결하기

갤럭시 폰과 삼성 헬스로 뛴 기록을 코치 서버에 올리면, 매일 아침 텔레그램으로 오늘의 훈련 처방과 분석 카드가 도착합니다. 갤럭시는 아이폰처럼 완전 자동은 어렵고, 일주일에 한 번 파일을 올리는 2분짜리 습관이 필요합니다. 그 외에는 전부 자동입니다.

⏱ 처음 설정 약 10분🔁 매주 2분💸 비용 0원📱 필요 기기 갤럭시 폰 (+ 갤럭시 워치 권장)

시작 전에 준비할 것

  • 삼성 헬스 앱 (갤럭시에 기본 설치). 러닝은 갤럭시 워치의 삼성 헬스 → 달리기, 또는 워치가 없으면 폰 삼성 헬스 앱의 운동 시작 → 달리기 로 기록해 주세요. 심박수는 워치가 있어야 남습니다.
  • 텔레그램 앱 (Play 스토어에서 무료 설치). 브리핑이 여기로 옵니다.
  • 크루장에게 받을 것: 본인 전용 올리기 주소. 모양은 https://yrc-coach.onrender.com/upload/본인코드 입니다. 1단계를 하면 자동으로 옵니다.

1

텔레그램 봇 연결

브리핑을 받을 창구입니다. 크루장이 회원 등록을 해야 하니 끝나면 꼭 알려주세요.

  1. 텔레그램 앱을 열고 위쪽 검색창에 Runnerai1030_bot 입력.
  2. 검색 결과에서 YRC 러닝 코치 봇(@Runnerai1030_bot)을 누릅니다.
  3. 아래 시작 버튼(또는 /start)을 누릅니다.
  4. 크루장에게 "봇 시작 눌렀어요" 라고 알립니다. 크루장이 이름·나이·목표를 등록하면 봇에서 "연결 완료" 메시지가 오고, 그 안에 본인 전용 주소가 들어 있습니다.
✔ 확인 봇 대화창에 "연결 완료" 메시지가 오면 성공. 메시지 안의 …/upload/본인코드 주소가 4단계에서 쓸 올리기 주소입니다. 길게 눌러 복사해 두거나, 삼성 인터넷/크롬에서 열어 홈 화면에 추가해 두면 매주 한 번 누르기만 하면 됩니다.
⚠ 주의 이 주소는 본인 데이터가 저장되는 열쇠입니다. 다른 사람에게 보내지 마세요.
2

러닝은 이렇게 기록

코치는 삼성 헬스의 "운동" 기록(거리·시간·평균 심박·최대 심박)을 씁니다. 다른 앱으로 기록하면 삼성 헬스에 안 남을 수 있습니다.

  1. 갤럭시 워치가 있으면: 워치에서 삼성 헬스 → 운동 → 달리기 → 시작. 끝나면 완료. 워치가 폰과 연결되어 있으면 기록이 자동으로 폰 삼성 헬스에 들어갑니다.
  2. 워치가 없으면: 폰 삼성 헬스 앱 → 홈 화면 운동 카드 → 달리기 → 시작. GPS로 거리를 잽니다. (심박은 안 남지만 코치는 페이스만으로도 처방합니다)
  3. 나이키 런 클럽 같은 다른 앱을 쓰고 있다면 그 앱 설정에서 삼성 헬스와 연동을 켜 두세요. 그러면 삼성 헬스에도 기록이 남습니다.
💡 폰 삼성 헬스 → 하단 함께하기 옆 내 정보(또는 홈의 운동 기록)에서 오늘 러닝이 보이면 정상적으로 남은 것입니다.
3

기록 파일 내려받기

삼성 헬스에는 "내 데이터를 파일로 내려받기" 기능이 있습니다. 이 파일을 서버에 올리면 러닝만 골라서 저장됩니다.

  1. 폰에서 삼성 헬스 앱을 엽니다.
  2. 오른쪽 아래 내 정보 (또는 오른쪽 위 ⋮/≡) → 설정 (톱니바퀴).
  3. 아래로 내려 개인 데이터 다운로드 를 누릅니다. (버전에 따라 "개인정보 및 데이터" → "개인 데이터 다운로드")
  4. 다운로드 → 삼성 계정 비밀번호를 물으면 입력합니다. 1~2분 뒤 "다운로드 완료" 알림이 옵니다.
  5. 파일은 내 파일 앱 → 내장 저장공간 → Download → Samsung Health 폴더에 samsunghealth_이름_날짜.zip 으로 저장됩니다. 찾아두기만 하면 됩니다.
✔ 확인 내 파일 앱에서 zip 파일이 보이면 됩니다. 크기는 보통 수 MB 입니다.
4

올리기 (매주 2분)

이 단계만 매주 반복합니다. 일요일 저녁처럼 요일을 정해두면 편합니다. 같은 러닝이 여러 번 올라가도 서버가 알아서 합칩니다.

  1. 인터넷 앱(삼성 인터넷 또는 크롬)에서 1단계의 올리기 주소를 엽니다. (홈 화면에 추가해 두었다면 그 아이콘)
  2. "러닝 기록 올리기" 화면에서 파일 선택 을 누릅니다.
  3. 파일 선택 창에서 내 파일 → Download → Samsung Health → 방금 받은 samsunghealth_….zip 선택.
  4. 올리기 버튼을 누릅니다. 10~30초 뒤 "✅ 러닝 ○건을 저장했습니다" 와 최근 러닝 목록이 나오면 성공.
✔ 확인 결과 목록에 본인의 최근 러닝(날짜·거리·시간·평균심박)이 맞게 보이면 됩니다. 처음 올릴 때는 크루장에게 "올렸어요" 라고 알려주세요.
💡 처음 한 번은 과거 기록도 같이 다운로드 파일에는 지난 기록이 전부 들어 있어서, 첫 업로드만으로 최근 몇 달 러닝이 서버에 들어갑니다. 그래서 첫날부터 정확한 분석이 됩니다.
5

매일 이렇게 돌아가요

매주 1회3~4단계로 파일을 올립니다 (2분). 자주 올릴수록 브리핑이 최신 기록을 반영합니다. 매일 07:00서버가 지금까지 올라온 기록으로 분석해서 텔레그램으로 카드 이미지 1장 + 브리핑 글을 보냅니다. 아무 때나브리핑 페이지 https://yrc-coach.onrender.com/brief/본인코드 에서 오늘 카드와 글을 다시 볼 수 있습니다.

브리핑에 나오는 것

항목뜻
컨디션최근 훈련량(과 심박 기록이 있으면 회복 상태)을 보고 오늘 강하게 뛰어도 되는지 판단. "조심"이면 편하게, "휴식 권장"이면 쉬기.
훈련량 (평소 대비 %)지난 7일 거리 ÷ 최근 4주 평균. 100%가 평소 수준, 130% 넘으면 부상 위험이 올라가서 다음 주는 유지·감량 권장.
오늘 훈련종류(쉬운/템포/인터벌/장거리/휴식), 거리, 목표 페이스, 구성. 페이스는 본인 최근 기록으로 계산.
VDOT · 예상 기록최근 최고 러닝으로 계산한 체력 지수와 5K·10K·하프 예상 기록. 올라가면 체력이 는 것.
강도 분포최근 28일 러닝 중 쉬운 강도 비율(워치 심박 기준). 70~80%가 이상적.
⚠ 알아둘 점 파일을 올린 시점까지의 기록으로 분석합니다. 어제 뛰고 파일을 안 올렸다면 오늘 브리핑에는 어제 러닝이 없습니다. 중요한 훈련 뒤에는 바로 올리는 습관이 좋습니다.
6

더 편하게 만들기 (선택)

  1. 홈 화면 아이콘: 올리기 주소를 연 상태에서 브라우저 메뉴 → 홈 화면에 추가. 매주 아이콘 하나 누르고 파일 고르면 끝.
  2. 알림 만들기: 삼성 리마인더나 캘린더에 "일요일 저녁 러닝 기록 올리기" 반복 알림.
  3. 완전 자동화를 원하면: 유료 앱 Tasker(약 5,000원, 1회 결제)와 헬스 커넥트로 매일 자동 전송을 만들 수 있습니다. 원하는 크루원이 있으면 크루장에게 문의하세요. 따로 설정을 도와드립니다.

막혔을 때

"개인 데이터 다운로드" 메뉴를 못 찾겠어요

삼성 헬스 앱을 최신으로 업데이트한 뒤, 앱 안 검색(설정 화면 위 검색창)에 "다운로드" 라고 쳐보세요. 그래도 없으면 삼성 헬스 → 설정 → 개인정보 보호 안을 확인하세요.

올렸는데 "러닝 기록을 찾지 못했습니다" 라고 나와요
  • 파일이 samsunghealth_….zip 이 맞는지 확인하세요. 압축을 풀어서 폴더를 올리면 안 됩니다.
  • 삼성 헬스에 러닝이 "달리기" 운동으로 저장되어 있는지 확인하세요. "걷기"로 기록되면 제외됩니다.
  • 그래도 안 되면 zip 파일을 크루장에게 보내주세요. 직접 확인해 드립니다.
올리기 화면이 안 열려요 / 오래 걸려요

서버가 잠들어 있다가 깨어나느라 첫 접속이 30~50초 걸릴 수 있습니다. 잠시 기다렸다가 새로고침하세요.

심박수가 안 나와요

워치 없이 폰으로만 기록하면 심박은 없습니다. 이 경우 브리핑은 거리·페이스 기준으로 처방하고, 강도 분포 항목은 비어 있습니다.

브리핑이 안 와요
  • 텔레그램 봇 대화창을 나갔거나 차단하지 않았는지 확인 (다시 /start).
  • 크루장에게 알려주세요. 서버 기록으로 확인해 드립니다.
