아이폰으로 러닝 코치 연결하기

아이폰과 애플워치로 뛴 기록이 매일 아침 자동으로 코치 서버에 올라가고, 텔레그램으로 오늘의 훈련 처방과 분석 카드가 도착합니다. 처음 한 번만 아래 순서대로 설정하면 그 뒤로는 손댈 게 없습니다.

⏱ 소요 시간 약 30분💸 비용 0원📱 필요 기기 아이폰 + 애플워치

시작 전에 준비할 것

  • 애플워치 (SE 2세대 이상 또는 Series 6 이상). 러닝은 워치의 기본 운동 앱 → 실외 달리기로 기록해 주세요. 이 데이터로 코치가 분석합니다.
  • 텔레그램 앱 (App Store에서 무료 설치). 브리핑이 여기로 옵니다.
  • 크루장에게 받을 것: 본인 전용 전송 주소 한 줄. 모양은 https://yrc-coach.onrender.com/ingest/본인코드 입니다. 아직 못 받았다면 1단계를 먼저 하면 자동으로 옵니다.
  • iOS 17 이상 권장. 단축어 앱은 아이폰에 기본으로 들어 있습니다. 지웠다면 App Store에서 "단축어"를 다시 설치하세요.

1

텔레그램 봇 연결

브리핑을 받을 창구를 만드는 단계입니다. 크루장이 회원 등록을 해야 하니 끝나면 꼭 알려주세요.

  1. 텔레그램 앱을 열고 위쪽 검색창에 Runnerai1030_bot 을 입력합니다.
  2. 검색 결과에서 YRC 러닝 코치 봇(@Runnerai1030_bot)을 누릅니다.
  3. 화면 아래 시작 버튼(또는 /start)을 누릅니다.
  4. 크루장에게 "봇 시작 눌렀어요" 라고 알립니다. 크루장이 이름·나이·목표를 등록하면 봇에서 "연결 완료" 메시지가 오고, 그 안에 본인 전용 전송 주소가 들어 있습니다.
✔ 확인 봇 대화창에 "YRC 러닝 코치 연결 완료!" 메시지와 https://yrc-coach.onrender.com/ingest/… 주소가 보이면 성공. 이 주소는 3단계에서 씁니다. 메시지를 길게 눌러 복사해 두세요.
⚠ 주의 전송 주소는 본인 데이터가 저장되는 열쇠입니다. 다른 사람에게 보내지 마세요.
2

아이폰 설정 하나 켜기

단축어가 건강 데이터를 서버로 보낼 수 있게 허용하는 설정입니다. 안 켜면 마지막에 "이 동작은 허용되지 않습니다" 오류가 납니다.

  1. 설정 앱을 엽니다.
  2. 아래로 내려 앱 → 목록에서 단축어 를 누릅니다. (iOS 17 이하는 설정 첫 화면에 바로 "단축어"가 있습니다)
  3. 고급 을 누릅니다.
  4. 대량의 데이터 공유 허용 스위치를 켭니다. 확인 창이 뜨면 허용.
✔ 확인 스위치가 초록색이면 됩니다. 다른 스위치는 건드리지 않아도 됩니다.
3

단축어 만들기 (핵심)

아이폰 기본 단축어 앱으로 "건강 데이터를 모아서 서버로 보내기" 자동화를 만듭니다. 동작은 6개이고, 한 번 만들면 끝입니다. 화면 이름 그대로 따라 하세요. 15~20분 걸립니다.

💡 먼저 알아두면 편한 것 3가지
① 동작을 추가하면 항상 맨 아래에 붙습니다. 순서가 틀리면 동작을 길게 눌러 끌어서 옮기면 됩니다.
② 편집 중 왼쪽 위 < 를 누르면 자동 저장됩니다. 동작 하나 만들 때마다 한 번씩 나갔다 들어오면 날아갈 걱정이 없습니다.
③ "건강 샘플 찾기"를 추가했는데 문장이 "…건강 샘플 필터링" 으로 바뀌어 있으면, 파란 건강 샘플 토큰을 누르고 변수 지우기 를 누르세요. 다시 "찾기"로 돌아옵니다. (앞 동작의 결과가 자동으로 끼어들어서 생기는 현상입니다)

3-1. 새 단축어 열기

  1. 단축어 앱 → 아래 탭 나의 단축어 → 오른쪽 위 +.
  2. 맨 위 제목 옆 ∨ → 이름 변경 → YRC 데이터 전송 으로 바꿉니다.

3-2. 동작 ① 달리기 속도 찾기

  1. 아래 동작 검색 칸에 건강 샘플 입력 → 다음 조건에 맞는 건강 샘플 찾기 선택.
  2. 유형 옆 파란 값을 눌러 목록 위 검색창에 달리기 속도 입력 → 선택.
  3. 시작일 줄이 "다음 과거 기간 내에 있음 · 7 · 일" 처럼 있으면 숫자 7을 56으로 바꿉니다. 시작일 줄이 없으면 필터 추가 → 시작일 → 조건을 다음 과거 기간 내에 있음, 56 일.
  4. 단위: km/h (KPH). 다음으로 그룹화: 시간.
  5. 그룹화를 바꾸면 파일이 유실됨 이라는 스위치가 생깁니다. 꺼진 상태로 둡니다. 제한 스위치도 꺼진 상태.

3-3. 동작 ② 걷기+달리기 거리 찾기

  1. 다시 동작 검색 → 건강 샘플 → 다음 조건에 맞는 건강 샘플 찾기.
  2. 문장이 "필터링" 으로 나오면 위의 팁 ③대로 건강 샘플 토큰 → 변수 지우기.
  3. 유형: 걷기 + 달리기 거리. 시작일: 과거 56일. 단위 km. 그룹화 시간. 파일이 유실됨 끄기. 제한 끄기.
  4. 필터 추가 → 소스 이름 (없으면 "소스") → 조건 다음을 포함 → 값 칸에 Watch 입력.
    아이폰과 워치가 같은 거리를 두 번 기록하기 때문에 워치 것만 쓰는 설정입니다. 안 넣으면 거리가 2배로 잡힙니다.

3-4. 동작 ③ 심박수 찾기

  1. 동작 검색 → 건강 샘플 → 찾기 추가. "필터링"이면 변수 지우기.
  2. 유형: 심박수. 시작일: 과거 14일 (심박은 양이 많아서 2주만). 단위는 그대로. 그룹화: 없음. 제한 끄기.
  3. 값 필터는 넣지 않습니다.

3-4b. 동작 ③-2 달리기 보폭 길이 찾기 (케이던스용)

  1. 동작 검색 → 건강 샘플 → 찾기 추가. "필터링"이면 변수 지우기.
  2. 유형: 달리기 보폭 길이 (검색창에 "보폭"). 시작일: 과거 56일. 단위 m. 그룹화 시간. 파일이 유실됨 끄기. 제한 끄기.

속도 ÷ 보폭 = 분당 걸음 수(케이던스)입니다. 이 동작이 없어도 나머지는 동작하지만 케이던스 항목이 비어 있게 됩니다.

3-5. 동작 ④ 텍스트로 묶기

  1. 동작 검색 → 텍스트 → 노란 아이콘의 텍스트 (그냥 "텍스트"라고만 써 있는 것).
  2. 텍스트 칸에 아래 8줄의 제목을 그대로 타이핑합니다. 각 제목 아래 줄에 변수를 넣을 겁니다. 
    ##speed_dates
(여기: 동작① 시작일)
##speed_values
(여기: 동작① 건강 샘플)
##distance_dates
(여기: 동작② 시작일)
##distance_values
(여기: 동작② 건강 샘플)
##hr_dates
(여기: 동작③ 시작일)
##hr_values
(여기: 동작③ 건강 샘플)
##stride_dates
(여기: 동작③-2 시작일)
##stride_values
(여기: 동작③-2 건강 샘플)
  3. 변수 넣는 법 (괄호 부분을 지우고 그 자리에):
    1. 커서를 그 줄에 두고 키보드 위 변수 선택 을 누릅니다. 위쪽 동작들이 파랗게 표시됩니다.
    2. values 줄: 해당 "건강 샘플 찾기" 동작을 탭합니다. 파란 건강 샘플 토큰이 들어가면 끝.
    3. dates 줄: 같은 동작을 탭한 뒤, 들어간 건강 샘플 토큰을 한 번 더 누릅니다. 창이 뜨면 시작일 을 선택하고, 같은 창의 날짜 포맷 을 ISO 8601 로 바꿉니다. (시간 포함 스위치가 있으면 켜기)
  4. 8줄 모두 토큰이 들어갔는지 확인합니다. dates 줄 토큰은 "시작일", values 줄 토큰은 "건강 샘플" 이라고 보여야 합니다.
⚠ 흔한 실수 ①②③ 동작이 텍스트 동작보다 위에 있어야 변수 선택 목록에 나옵니다. 아래에 있으면 텍스트 동작을 길게 눌러 맨 아래로 내리세요. 토큰을 눌렀는데 "시작일"이 안 보이면 그 창의 유형 이 "건강 샘플"인지 확인하세요.

3-6. 동작 ⑤ 서버로 보내기

  1. 동작 검색 → URL 콘텐츠 → URL 콘텐츠 가져오기.
  2. URL 칸에 1단계에서 받은 본인 전송 주소를 붙여넣습니다.
  3. 오른쪽 화살표 ∨ 를 눌러 펼친 뒤: 메소드 POST, 본문 요청 파일, 파일 칸을 눌러 변수 선택 → 바로 위 텍스트 동작을 탭.
✔ 확인 위에서 아래로 순서가 찾기 4개 → 텍스트 → URL 콘텐츠 가져오기 6개면 완성입니다. 왼쪽 위 < 로 나가서 저장하세요.
4

한 번 실행해서 확인

  1. 단축어 편집 화면 오른쪽 아래 ▶︎ 를 누릅니다.
  2. 건강 데이터 접근 허용 창이 뜨면 오른쪽 위 모두 켜기 → 허용. (처음 한 번만)
  3. 허용 직후 실행은 빈 결과가 나올 수 있으니 ▶︎ 를 한 번 더 누릅니다. 10~30초 걸립니다.
  4. 오류 없이 끝나면 크루장에게 "실행했어요" 라고 알립니다. 크루장이 서버에서 러닝이 몇 건 들어왔는지 확인해 줍니다.
✔ 확인 크루장이 "○건 들어왔어요" 라고 하면 성공. 본인 브리핑 페이지(https://yrc-coach.onrender.com/brief/본인코드)를 Safari로 열어 홈 화면에 추가해 두면 언제든 볼 수 있습니다.
"네트워크 연결이 유실되었습니다" 라고 나와요

서버가 잠들어 있다가 깨어나느라 첫 요청이 늦어진 겁니다. 30초 뒤 ▶︎ 를 다시 누르면 됩니다. 두 번 연속 실패하면 크루장에게 알려주세요.

"이 동작이 ○○개의 건강 항목을 공유하려고 하며 허용되지 않습니다"

2단계 대량의 데이터 공유 허용 이 꺼져 있습니다. 켜고 다시 실행하세요.

실행이 몇 분째 안 끝나요

동작 ③(심박수)의 그룹화가 "시간" 으로 되어 있거나, 반복문 동작이 들어가 있을 때 느려집니다. 심박수는 그룹화 없음, 14일로 맞추세요. 반복(각 항목에 대해 반복) 동작이 있으면 삭제합니다.

5

매일 자동 실행 걸기

아침 6시 40분에 단축어가 스스로 돌아가게 합니다. 7시 브리핑보다 앞서야 그날 데이터가 반영됩니다.

  1. 단축어 앱 아래 탭 자동화 → 오른쪽 위 +.
  2. 목록에서 시간대 선택.
  3. 시간 오전 6:40, 반복 매일.
  4. 아래 실행 방식에서 즉시 실행 을 선택합니다. ("실행 전에 확인"이면 매일 아침 눌러줘야 하니 꼭 즉시 실행) "실행 시 알림"은 꺼도 됩니다. → 다음
  5. 단축어 목록에서 YRC 데이터 전송 선택 → 완료.
✔ 확인 자동화 탭에 "매일 오전 6:40 · YRC 데이터 전송" 카드가 보이면 됩니다. 다음 날 아침 그 카드를 누르면 실행 기록이 보입니다.
💡 아이폰이 밤새 꺼져 있거나 저전력 모드면 자동화가 건너뛸 수 있습니다. 그런 날은 단축어를 손으로 한 번 실행하면 됩니다. 같은 기록을 여러 번 보내도 서버가 알아서 합칩니다.
6

과거 기록 넣기 (선택)

단축어는 최근 8주를 보내지만 근사치입니다. 건강 앱의 정확한 과거 기록을 한 번 넣어두면 첫날부터 정확한 페이스·심박으로 분석됩니다.

  1. 건강 앱 → 오른쪽 위 프로필 사진 → 맨 아래 모든 건강 데이터 내보내기 → 내보내기. 몇 분 걸립니다.
  2. 만들어진 내보내기.zip 을 크루장에게 보냅니다 (에어드롭 또는 카카오톡 파일). 크루장이 서버에 넣어 줍니다. 파일이 커서(수십~수백 MB) 직접 올리기보다 이 방법이 확실합니다.

항목뜻
컨디션안정심박·HRV·최근 훈련량을 보고 오늘 강하게 뛰어도 되는지 판단. "조심"이면 편하게, "휴식 권장"이면 쉬기.
훈련량 (평소 대비 %)지난 7일 거리 ÷ 최근 4주 평균. 100%가 평소 수준, 130% 넘으면 부상 위험이 올라가서 다음 주는 유지·감량 권장.

유형 목록에 "운동" 이 없어요

정상입니다. 아이폰 단축어는 운동 기록을 직접 못 꺼내서, 대신 "달리기 속도"와 "심박수"로 서버가 러닝을 복원합니다. 안내대로 세 가지 유형만 쓰면 됩니다.

"달리기 속도" 유형이 없거나 데이터가 없어요

건강 앱 → 둘러보기 → 활동 → 달리기 속도 에 최근 러닝 그래프가 있는지 확인하세요. 없으면 워치가 오래된 모델이거나 러닝을 워치 운동 앱으로 기록하지 않은 경우입니다. 크루장에게 알려주세요. 그 경우 갤럭시 안내문의 "기록 올리기" 방식(건강 앱 내보내기 파일을 주기적으로 전달)으로 대신할 수 있습니다.

변수 선택을 눌렀는데 찾기 동작이 파랗게 안 떠요

그 찾기 동작이 텍스트 동작보다 아래에 있어서입니다. 텍스트와 URL 동작을 길게 눌러 맨 아래로 옮기세요.

브리핑이 안 와요
  • 텔레그램 봇 대화창을 실수로 나갔거나 차단하지 않았는지 확인 (다시 /start).
  • 자동화 탭에서 오늘 06:40 실행 기록이 있는지 확인. 없으면 단축어를 손으로 실행.
  • 그래도 안 오면 크루장에게 알려주세요. 서버 기록으로 어디서 끊겼는지 볼 수 있습니다.
거리가 실제보다 크게 나와요

동작 ②에 소스 이름 다음을 포함 "Watch" 필터가 빠진 경우입니다. 아이폰과 워치 기록이 합쳐져 2배로 잡힙니다.

단축어를 잘못 만들어서 처음부터 다시 하고 싶어요

나의 단축어에서 카드를 길게 눌러 삭제하고 3단계부터 다시 하면 됩니다. 서버에 이미 올라간 데이터는 그대로 남습니다.
