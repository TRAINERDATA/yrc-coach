# 크루장 운영 가이드

크루원을 추가하고 매일 브리핑이 전원에게 나가게 하는 방법입니다. 모든 명령은 PC 의 `C:\Desktop\김창희\yrc-coach` 폴더에서 실행합니다.

## 1. 크루원 추가 (한 명당 2분)

1. 크루원에게 안내문을 보냅니다.
   - 아이폰: `docs/크루원안내_아이폰.html` (또는 공유 링크)
   - 갤럭시: `docs/크루원안내_갤럭시.html` (또는 공유 링크)
2. 크루원이 텔레그램 봇(@Runnerai1030_bot)에 `/start` 를 누르면 아래 명령을 실행합니다. 3분 안에 자동으로 잡아서 등록하고, 봇으로 안내 메시지(전송 주소·올리기 주소)를 보내 줍니다.
   ```
   python -m app.cli telegram-setup --name 홍길동 --age 30 --goal "10km 55분" --weekly-days 3
   ```
3. 서버(Render)에도 같은 사용자를 만들어야 합니다. 아래 명령이 출력한 한 줄을 복사해서 Render → yrc-coach → Environment → `SEED_USERS` 값에 **통째로 교체** → Save. (서버가 재시작되며 사용자 목록이 갱신됩니다)
   ```
   python -m app.cli export-seed
   ```
4. 크루원이 보낸 주소 확인: 봇 메시지의 `…/ingest/<코드>` 는 아이폰 단축어용, `…/upload/<코드>` 는 갤럭시 올리기용, `…/brief/<코드>` 는 브리핑 페이지입니다. (올리기 주소는 ingest 를 upload 로 바꾸면 됩니다)

## 2. 전원 브리핑 (한 번만 설정)

지금 cron-job.org 의 07:00 작업은 크루장 한 명의 주소를 호출합니다. 전원에게 보내려면:

1. Render → Environment → `ADMIN_KEY` 를 추가하고 값은 아무 긴 문자열(예: 영문+숫자 24자)로 → Save.
2. cron-job.org 의 `yrc brief` 작업 URL 을 `https://yrc-coach.onrender.com/run-all/<ADMIN_KEY>` 로 바꿉니다 (POST 그대로).

## 3. 크루원 데이터 확인

- 서버가 마지막으로 받은 원본: `https://yrc-coach.onrender.com/ingest/<코드>/last`
- 분석 요약(JSON): `https://yrc-coach.onrender.com/brief/<코드>/json`
- 지금 바로 브리핑 보내기: `curl -X POST https://yrc-coach.onrender.com/brief/<코드>/run`

## 4. 과거 기록 넣기 (아이폰 크루원의 내보내기 zip)

```
python -m app.cli import-health <user_id> 내보내기.zip --days 120
```
로컬 DB 에 들어갑니다. 서버에도 남기려면 `seed/history.json` 에 그 사용자의 token 키로 workouts/metrics 를 추가하고 push 하세요 (크루장 본인 기록이 들어간 형식 참고).

## 5. 자주 하는 점검

| 증상 | 확인 |
|---|---|
| 브리핑이 안 옴 | cron-job.org 실행 기록 → 서버 `/health` → Render Logs |
| 러닝이 0건 | `/ingest/<코드>/last` 에 데이터가 있는지, `hourly_hours` 카운트 |
| 거리 2배 | 아이폰 단축어 거리 동작에 소스 "Watch" 필터 빠짐 |
| 재배포 후 사용자 사라짐 | `SEED_USERS` 최신인지 |
